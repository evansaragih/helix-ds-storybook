Hypothesis test

About the test types

Microbiome data often departs from normality [1], so alpha diversity is compared with non-parametric Wilcoxon tests, in line with established practice in microbiome studies [2].

  • IndependentWilcoxon rank-sum test, for comparing separate groups.
  • PairedWilcoxon signed-rank test, for matched samples such as the same subjects over time (longitudinal studies).

Before running the test, make sure your data is set up correctly.

References [1] doi:10.1016/j.gendis.2017.06.001 [2] doi:10.1128/msphere.00354-23

Why a subject ID?

Required for a paired test. Samples are matched across groups by this column, so each pair holds the same subject's values.
