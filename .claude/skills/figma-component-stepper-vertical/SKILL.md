# Stepper Vertical — Component Characteristics

Node `7034:1249` on the **Stepper** page, Nusantics Design System Figma file
(`GWzBKGr6512AeMOapwgQhj`). Companion to `figma-component-build` (general
build/audit rules) — this file is the per-component cheat sheet.

## What it is / when to use it

Vertical step navigation: markers + connectors in one column, step title/description/badge beside them. Label Position controls which side the label sits on (Right=default, Left=mirrored). Use inside a Stepper flow panel. Do not use for the horizontal layout — use Stepper Horizontal instead.
