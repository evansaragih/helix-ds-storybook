# Button — Component Characteristics

Node `2826:41666` on the **Button** page, Nusantics Design System Figma file
(`GWzBKGr6512AeMOapwgQhj`). Companion to `figma-component-build` (general
build/audit rules) — this file is the per-component cheat sheet.

## What it is / when to use it

Core action button. Use for the primary action in a view, supporting actions, or a destructive/irreversible action (Hierarchy). Do not use for a standalone icon-only action outside text context — use IconButton instead.

**Code:** `Button from helix-design-system`
