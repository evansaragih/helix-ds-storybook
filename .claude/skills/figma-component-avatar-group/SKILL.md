# Avatar Group — Component Characteristics

Node `2062:24519` on the **Avatar** page, Nusantics Design System Figma file
(`GWzBKGr6512AeMOapwgQhj`). Companion to `figma-component-build` (general
build/audit rules) — this file is the per-component cheat sheet.

## What it is / when to use it

Stack of overlapping Avatar instances for showing multiple users/participants in one compact cluster. Size (xs/sm/md) scales every avatar in the group uniformly. Add user button=True appends a trailing '+' action avatar; More users=True appends a trailing '+N' overflow avatar.

## Variant axes & properties

- `Size`
- `Add user button`
- `More users`
