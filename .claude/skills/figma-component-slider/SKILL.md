# Slider — Component Characteristics

Node `2010:105` on the **Slider** page, Nusantics Design System Figma file
(`GWzBKGr6512AeMOapwgQhj`). Companion to `figma-component-build` (general
build/audit rules) — this file is the per-component cheat sheet.

## What it is / when to use it

A draggable track control for selecting a numeric value in a range. Use for continuous numeric input (e.g. volume, price range). Do not use for a small fixed set of discrete options — use Radio Group or Tabs instead.

- `State`
- `Size`
- `Color`
