# Skeleton — Component Characteristics

Node `7278:1692` on the **Loading States** page, Nusantics Design System Figma file
(`GWzBKGr6512AeMOapwgQhj`). Companion to `figma-component-build` (general
build/audit rules) — this file is the per-component cheat sheet.

## What it is / when to use it

A neutral placeholder block that stands in for content while it loads. Use for composing loading layouts that mirror the final content shape (text line, title, avatar, image). Do not use for a wait where the layout is unknown — use Loading State with Type=Spinner instead.
